  规则口径（本原型采用）
  

    
    
      
  • 点箭头方块，它会沿箭头方向滑出去。
    • 
      
  • 把精灵球推进洞里即可通关。
    • 
      
  • 箭头是一次性的；撤回 / 重置 / 换一题随时可用。
    • 
    

  






  宝可梦联动提案
  

    
球球归位（活动名备选：洞窟撞球）

    
    
      
  • 洞：普通的洞。只画洞口，不放表情。
    • 
      
  • 球：精灵球。要把它撞进洞里。
    • 
      
  • 箭头方块：铁哑铃 / 方向石，一次性冲撞。点击后“猛撞”滑行，撞上东西就消失；正式版可换成铁哑铃立绘，角上叠一个小箭头。
    • 
      
  • 碎岩：可破坏的岩石，对应「碎岩」招式；球/箭头撞到它时停在它前一格，碎岩碎掉消失。
    • 
      
  • 整体气质接近现有「箭头迷宫」：沙色棋盘、无墙场地、低饱和绿 UI；不加渐变和阴影。
    • 
    

  






  生成器怎么保证有解
  

    
不是先撒东西再碰运气，而是先布线、再验证：

    
    
      
  • 从球的位置开始，随机铺一条“球被推 N 次”的路径：每次在球后方放一只推手，在前方放一个刹车点（边界或碎岩）。每个推手只用一次，正好对应一次性箭头。
    • 
      
  • 困难档把其中一个推手换成三角箭头：球只被推一格，用来做细定位。
    • 
      
  • 普通/困难把其中一个推手改成中转：目标箭头一开始在球的行/列外，先用另一只箭头把它推到球后方；最短解必须包含这次箭头推箭头。
    • 
      
  • 最后一步强制让终点线避开初始球所在的行/列，避免开局一步直塞。
    • 
      
  • 把候选关卡交给 BFS 求解器；拒绝无解、最短解短于设计步数、或存在一步直塞的关卡。
    • 
      
  • 通过后再撒多余碎岩（只放在不挡已知解的位置）。
    • 
      
  • 随机数走 mulberry32，同一个种子必定复现同一关。
    • 
      
  • 外部检索受网络限制没找到可直接复用的开源实现；这里用的是 Ricochet Robots / 冰面滑行类滑动谜题的“构造 + BFS 验证”思路。
    •

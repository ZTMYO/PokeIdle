# 口袋挂机

基于 Tauri v2 的桌面挂机游戏。纯前端 HTML/CSS/JS + Rust 后端存档。

## 功能

- **挂机冒险** — 你是在丰缘长大的冠军级训练家，如今九大地区（关都、城都、丰缘、神奥、合众、卡洛斯、阿罗拉、伽勒尔、帕底亚）陆路打通；拥有精灵球时每 2~4 分钟遇到一只野生宝可梦，行走自动拾取道具，目标完成全图鉴
- **手机系统** — 点击标题栏手机按钮进入主页，内置导航、图鉴、宝可梦（仓库）、交换、孵蛋器、树果农场、混合器、日志、教程、统计等应用
- **导航** — 手动选择目的地走最短路线；开启漫游后自动沿环国路线（合众→关都→卡洛斯→城都→阿罗拉→丰缘→伽勒尔→神奥→帕底亚→循环）选择下一站，到达后自动续接；进度由主角实际移动驱动，跑步更快，遇敌/钓鱼时暂停
- **地区** — 9 个地区出没的宝可梦各不相同；地区间道路每段路前半程算出发地区、后半程算目标地区，刷怪与悬赏按当前位置归属
- **捕捉** — 精灵球/高级球/大师球三种球，基础捕获率 30%/70%/100%（再乘宝可梦个体难度）；挣脱后逃跑率 5% 起步、每球 +5%、上限 50%；逃跑率拉满后每多丢一球捕获率 +10%，无上限；支持主动逃跑
- **闪光** — 1/1000 概率遇见闪光个体，带出场粒子特效，图鉴特殊标记；使用闪耀护符可大幅提升遇闪概率
- **道具** — 挂机掉落与钓鱼收获：精灵球、高级球、大师球、糖果、甜甜蜜、神秘蛋、闪耀护符，稀有度权重逐级降低
- **商店** — 消耗糖果兑换道具（精灵球、高级球、大师球、甜甜蜜、神秘蛋、闪耀护符）
- **增益** — 甜甜蜜与闪耀护符持续 60 秒：遇敌间隔从 2~4 分钟缩短到 15~30 秒；甜甜蜜提升极稀有出现权重，闪耀护符提升闪光率；倒计时仅在挂机等待时消耗（遇敌/钓鱼暂停）
- **孵蛋** — 神秘蛋放入孵蛋器孵化，最多 8 个槽位（全部需糖果解锁、价格递增）；孵化时间由宝可梦体重与稀有度决定，30 分钟~8 小时区间呈正态分布；结果完全随机，1/1000 概率闪光
- **交换** — 每半小时刷新一波 6 位 NPC 交换请求：NPC 提出想要的宝可梦（可要求特定性格或某项个体值下限），同时展示自己愿意给出的宝可梦（个体值/性格/闪光直接可见）；从仓库挑选符合要求的个体即可交换，获得的宝可梦计入图鉴并写入遭遇日志，来源记为「交换」，完成后可跳转图鉴查看
- **宝可梦仓库** — 手机「宝可梦」应用管理所有个体：搜索、来源筛选（野生/钓鱼/孵蛋/交换/闪光）、表头排序，详情页展示六围个体值雷达图、性格与来源；多余个体可放生（告别动画确认，不可恢复）
- **钓鱼** — 途经带垂钓点的水域路段自动停下钓鱼，每段路只钓一次；10% 几率钓到宝可梦（增益期间 50%，其中 60% 为极稀有），其余收获随机道具 1~10 个
- **树果农场** — 种下树果种子（10 糖果/棵）、浇水养护（湿度归零停止生长），30~60 分钟随机成熟，收获 2~4 颗存入库存；告示牌每日刷新需求，用库存树果兑换糖果
- **树果混合器** — 从农场库存选 1~4 颗树果作配方制成树果方块：先玩转盘 QTE（5 轮、速度渐快）按成绩评定品质（完美/优秀/良好/一般/劣质），品质决定遇敌时直接遇到目标宝可梦的概率（95%/85%/70%/50%/25%）；方块按行走里程计时，再走 1000 米未被吃掉则风干失效
- **地区悬赏** — 每个地区每天 0 点刷新 5 条悬赏（指定宝可梦来自全国图鉴、各地区互不重复），糖果奖励 30~500 颗、越难捕获越高；今日到访过的地区才能查看，当日捕获指定宝可梦即可领取（野生/钓鱼/孵蛋都算），但领取必须到达对应地区；每日刷新，未领取不累积
- **统计** — 欧非评定（按遭遇稀有度与捕获运气综合出称号）、挂机时长、遭遇/捕获/逃跑/闪光、捕获率、图鉴完成度、行走距离、道具累计获得、农场与合成、地区悬赏等全量冒险数据
- **图鉴** — 1025 只宝可梦（第 1~9 世代全收录），支持搜索、地区筛选、字段排序、详情页（未遇见/遇见过/已捕获三级解锁），记录每次遭遇与捕获
- **自动操作** — 遇敌自动处理：勾选球种自动捕获（根据捕获率智能选球），不勾球种自动逃跑，可自动续杯增益道具，闪光出现时可暂停自动操作
- **佛系模式** — 与自动操作互斥，遇敌 30 秒未操作则宝可梦自行逃跑，不会卡住进度，适合挂后台偶尔手动抓
- **系统日志** — 手机日志应用记录最近活动（获得道具、遇敌、捕捉、悬赏领取等），最多保留 50 条
- **离线挂机** — 离线期间道具按掉率持续累计（上限 24 小时），行走/地区进度不推进，回到游戏自动结算并提示离线时长
- **存档** — localStorage + Rust 后端双通道保存，自动存档每 30 秒一次

## 开发

### 前置依赖

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/) 1.70+
- [Tauri v2 CLI](https://v2.tauri.app/)

### 启动

```bash
npm install
npm run dev
```

### 构建

```bash
npm run build
```

构建产物输出到 `src-tauri/target/release/bundle/nsis/`，生成 NSIS 安装包。

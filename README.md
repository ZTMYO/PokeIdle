# 口袋挂机

基于 Tauri v2 的桌面挂机游戏。纯前端 HTML/CSS/JS + Rust 后端存档。

## 功能

- **挂机遇敌** — 自动遇敌、丢球、捕获，支持智能选球；挣脱后逃跑率随丢球递增（5% 起步，每球 +5%，上限 50%），逃跑率拉满后每多丢一球捕获率 +10%，无上限
- **佛系模式** — 与自动操作互斥，遇敌 30 秒未操作则宝可梦自行逃跑，适合挂后台偶尔手动抓
- **9 个世代地区轮转** — 每 1 小时切换一个地区，只能遇到当前地区的宝可梦
- **1025 只宝可梦** — 涵盖第 1~9 世代全部宝可梦，带稀有度权重出率
- **闪光系统** — 极低概率遇见闪光个体，带出场粒子特效
- **图鉴** — 列表/详情/搜索/筛选/排序，记录每次遭遇与捕获
- **教程** — 设置页内置玩法教程，覆盖遇敌/捕捉/钓鱼/孵蛋等，数值随配置动态显示
- **商店** — 糖果兑换精灵球、甜甜蜜、神秘蛋、闪耀护符
- **道具** — 甜甜蜜（吸引精灵、提升稀有度出率）、闪耀护符（大幅提升闪光率）、神秘蛋（放入孵蛋器等待孵化，孵化时间由宝可梦体重与稀有度决定，在 30 分钟~8 小时区间内呈正态分布），孵化结果完全随机，1/1000 概率闪光）
- **钓鱼** — 在有垂钓点的水上路段（石桥等）自动停下钓鱼，每段路只钓一次，等待上钩后有 10% 几率钓到宝可梦（甜甜蜜/闪耀护符生效期间提升至 50%，其中 60% 为极稀有），其余收获随机道具 1~10 个
- **孵蛋器**：最多 8 个槽位（2×4 排列），全部需糖果解锁
- **存档** — localStorage + Rust 后端双通道保存

## 开发

### 前置依赖

- [Node.js](https://nodejs.org/) 18+
- [Rust](https://www.rust-lang.org/) 1.70+
- [Tauri v2 CLI](https://v2.tauri.app/)

### 启动

```bash
npm install
npm run dev
```

### 构建

```bash
npm run build
```

构建产物输出到 `src-tauri/target/release/bundle/nsis/`，生成 NSIS 安装包。

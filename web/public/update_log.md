# 更新日志
## v1.22 性能优化
### 调整
1. **存档写入合并** — 一场遭遇里连续几次保存会合并成一次，手机端不再重复写一份本地备份，写盘造成的卡顿明显减少
2. **仓库列表虚拟滚动** — 只渲染当前可见的几十行，几千只的仓库打开时不再卡住上屏
3. **图鉴列表分片渲染** — 上千条目不再一次性铺满，切换页面更顺
4. **高刷屏按 60fps 绘制** — 120Hz 屏幕不再重复绘制同一帧，减少无意义的重绘与发热
5. **挂机背景尺寸缓存** — 天空背景不再每帧读取布局，减少主线程抖动
6. **切页时暂停路面重绘** — 单屏切到其它页面时世界照常推进，路面画布不再空转
7. **启动读档** — 手机端主存档能读能解析时，不再多读并解析备份与外部镜像两份存档
8. **调整部分宝可梦图标** — 调整花叶蒂、未知图腾等宝可梦图标，和变体图标尺寸统一
### 修复
1. **单屏切页后图标残留** — 滚到一半的道具与宝可梦图标会留在其它页面上；现在会藏起来，到达主角时照常拾取与开战
2. **手机音乐栏歌名不滚动** — 歌名超出宽度后不再跑马灯；现在会正常滚动
3. **首次捕获提示** — 遭遇页右上角的已拥有图标手机端点击没反应，现在会正常响应

## v1.18 手机桌面整理、小游戏新增、收藏蛋
### 新增
1. **手机桌面整理** — 长按桌面上的任意图标即可整理：图标会抖动，拖动换位置（拖到屏幕边缘会翻页、翻到最后再往右会新开一页）；把一个图标拖到另一个上会合成「合集」，合集里最多放 9 个应用，也能拖进拖出、点名字改名。摆乱了可以一键恢复默认布局。
2. **鸟了个鸟** — 限时活动新增堆叠三消玩法
3. **游戏厅二楼 · 跳企鹅** — 一层左上角的楼梯可以上二层游戏机区（二层的楼梯回一层）。二楼第一台机器是「跳企鹅」：下注后点「前进」让冰砌鹅踩着浮冰往右跳，每一跳都有概率踩碎浮冰掉进水里，掉下去本局注额就没了；每站住一次提现额 ×1.25，随时可以提现，跳到最右自动结算
4. **收藏的蛋** — 宝可梦蛋页面右上角新增「收藏」：点击蛋列表里的任意一行可以「收藏」，被收藏的蛋会单独收进这个收藏页，不再和别的蛋混在一起（也不会出现在孵蛋器的放入列表里），以免被误丢；在收藏页点同一行可以「取消收藏」
5. **宝可连线** — 限时活动新增连线铺色玩法。
### 修复
1. **装完新版本第一次进游戏还是旧的** — 更新后首次启动可能仍在跑上一版的热更资源，要重启一次才恢复；现在包里的资源永远比热更缓存优先
2. **开了「闪光 / 神兽使用大师球」还是用大师球抓普通宝可梦** — 捕获率低的普通宝可梦会绕开这个开关直接吃掉大师球；现在勾上后这类最多用高级球，前两种球用光就自动逃跑，不浪费大师球
3. **分享图里看不出 RGB / 污染特效** — 时空扭曲抓到的特效宝可梦，分享出去的图一直是原色；现在分享图会照同样效果画出来
4. **自爆 / 反伤类招式效果不对** — 玉石俱碎、薄雾炸裂打完不会自己倒下；搏命没按「伤害等于自身剩余 HP」结算；惊爆大头、铁蹄光线、叶绿爆震缺按最大 HP 一半的反伤；临别礼物在配招里选不到，被守住挡下或没命中时也会自己倒下。现在这些招式都按原作效果结算
5. **孵蛋 / 进化演出占着游戏阶段** — 演出期间上屏的遭遇被反复打乱：路上的宝可梦被清掉，正在打的那只被换成蛋，自动捕捉停摆，结束后还会复活一只没有文字框、顶不掉的僵尸遭遇，站在事件区域内更会白扣一只数量。现在演出不再占用游戏阶段，和上屏的遭遇各走各的
6. **离线久了事件刷不出来** — 长时间不上线后，本地缓存里那份排期已全部跑完，游戏会一直等一个不会再来的时段，事件彻底不生成；现在排期整段翻篇就先作废，退回本地随机事件
7. **连续繁殖多轮时几秒出完全部蛋** — 第一颗蛋产出后，剩下的蛋会在几秒内一起入库，倒计时乱跳（12/18/24…）、进度条也不动；现在每轮各等一轮时长，离线回来仍会一次性补齐
8. **热更新只下到一半导致启动卡死** — 更新时部分文件下载失败，脚本却已经换成了新版，重启后卡在启动画面进不了游戏（也就没法再点更新）；现在整批文件都下完才生效，缺一个就留在旧版本并提示重试

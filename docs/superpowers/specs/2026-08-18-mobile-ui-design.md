# Android 移动端自适应 UI 设计

## 1. 背景与目标

当前 Android 端沿用桌面掌机的固定 `274 × 342` 设计尺寸。手机屏幕通常更高，等比放大后会在上下留下未利用空间；设置、仓库、图鉴等长内容页面也因此显得拥挤。

本次优化只调整 Android 移动端布局，桌面端继续保持现有掌机比例与视觉。目标是充分利用竖屏高度，同时保留 PokeIdle 的掌机风格、像素素材和现有业务流程。

## 2. 范围

### 包含

- Android 安全区内的动态竖向布局。
- 挂机、战斗、设置、仓库、图鉴、商店等主要页面的空间分配。
- 移动端触控尺寸、按下反馈、滚动边界和返回键层级。
- 存档确认层的移动端底部弹层布局。
- 视口变化、无效尺寸和旧 WebView 的兼容回退。

### 不包含

- 桌面端窗口尺寸、Tauri 行为和桌面 CSS 重构。
- 战斗规则、存档结构、数值平衡和素材替换。
- 账号、云同步、多存档槽位和新的导航信息架构。
- 重新设计配色或移除掌机外壳。

## 3. 设计方案

### 3.1 自适应掌机模型

Android 继续使用 `274 px` 的设计宽度，并按照安全区可用宽度等比缩放。与现状不同，设计高度不再固定为 `342 px`：根据安全区可用高度和缩放比例反算动态设计高度，让掌机内容填满竖屏。

该模型保持横向像素定位、精灵尺寸和现有页面结构稳定，只释放纵向空间。桌面端仍使用固定 `274 × 342`。

### 3.2 页面空间分配

- 挂机和战斗页面：主场景使用剩余高度，顶部标题栏、背包栏和状态栏保持固定。
- 设置、仓库、图鉴、商店、日志等页面：内容容器占满剩余高度，独立滚动；固定栏不遮挡最后一项。
- 背包栏：移动端维持稳定的网格尺寸和清晰的数量显示，不因视口变化导致布局抖动。
- 顶部操作区：保留手机、悬赏、商店、设置入口，压缩标题栏间距但不隐藏核心入口。

### 3.3 存档确认层

移动端确认层采用底部弹层：遮罩覆盖当前页面，弹层圆角贴底，摘要内容可滚动，底部「取消」和「覆盖当前存档」按钮固定。按钮最小触控高度约为 `44 px`，弹层打开时禁止背景滚动。

## 4. 响应式与触控规则

1. 移动桥接层从 `visualViewport` 读取可用宽高，并扣除安全区内边距。
2. 计算 `scale` 与动态设计高度，写入 CSS 变量；视口 resize 时重新计算。
3. Android CSS 规则全部限定在 `.mobile-mode` 下，桌面默认值不变。
4. 常用按钮、背包槽位和设置操作的触控区域达到约 `44 × 44` 物理像素，并提供按下反馈。
5. 页面滚动使用独立容器，避免 body 滚动和底部固定栏穿透。
6. Android 返回键优先关闭存档弹层，其次返回上一页面，最后才显示退出确认。
7. 视口无效、过矮或 WebView 缺少 `visualViewport` 时，回退到现有 `274 × 342` 等比布局。

## 5. 组件与数据流

### 5.1 视口计算

`mobile/bridge-source.js` 负责监听视口变化并收集安全区；`mobile/viewport-utils.mjs` 负责纯函数计算缩放与动态设计高度；CSS 使用变量完成布局，不将设备判断散落到业务页面。

### 5.2 页面布局

主要改动集中在 `src/styles.css` 的移动端覆盖规则，以及必要的 `src/index.html` 容器结构。业务模块继续通过现有 `showView`、滚动容器和状态栏更新逻辑工作。

### 5.3 弹层与返回键

存档确认控制器继续负责 Promise 结算、取消、覆盖和错误回滚；移动端仅改变弹层呈现和触控尺寸，不改变导入事务。返回键入口在弹层存在时先结算取消。

## 6. 容错与安全性

- 无效视口数据不抛出异常，不阻塞游戏启动。
- 动态高度不能小于最小内容高度，过矮设备保持当前等比策略并允许页面内部滚动。
- 弹层关闭时清理遮罩、滚动锁和事件监听，避免重启或页面切换后残留。
- 所有存档导入校验、备份、回滚逻辑保持不变。
- 移动端新增样式不得覆盖桌面端的 `view-scroll`、窗口控制和 Tauri 行为。

## 7. 验证计划

### 自动化测试

- 视口工具：正常竖屏、矮屏、安全区、无效尺寸和回退比例。
- 移动端 CSS 契约：移动端动态高度、固定栏、独立滚动和弹层按钮规则。
- 存档弹层：`pointerup`、`touchend`、`click` 均可取消或确认，关闭后监听器被清理。
- 现有 `npm run test:mobile` 全量回归。

### 真机验收

- `360 × 800` 和 `412 × 915` 竖屏：主页、战斗、仓库、设置、图鉴、商店。
- 带刘海和底部手势条的设备：内容不被安全区遮挡。
- 页面滚动到末尾：最后一行可见且不被状态栏覆盖。
- 存档导入确认：弹层按钮可触摸，返回键可取消，确认后流程不重复触发。
- 前后台切换和重新启动：不会自动显示存档确认层，布局恢复正确。

## 8. 发布边界

本设计完成后需要重新生成 Android release APK。版本号、包名、签名密钥和存档格式保持兼容；桌面构建和桌面 UI 不纳入本次发布回归范围之外的改动。

# 手机主页单屏整合设计

## 目标

将手机主页当前的两页应用列表整合为一个固定单屏，保留日期、时间、当前音乐、应用红点和全部应用入口，减少 Android 手机上进入应用前的翻页操作。

## 交互设计

- 手机主页显示全部 18 个应用，采用 6 列 × 3 行网格。
- 移除横向滚动、scroll-snap、页码圆点和桌面端滚轮翻页。
- 应用顺序沿用当前 `APPS` 数组，避免用户已有的操作记忆改变。
- 点击应用后的动态导入、导航栈和返回键行为保持不变。
- 孵蛋器、交换、农场和成就的红点继续由现有刷新函数更新。
- 顶部日期、时间和音乐信息保留；应用区域占据剩余高度。

## 布局与响应式

- `.phone-pages` 保留为现有 DOM 容器名称以减少改动，但改为不可滚动的单层 CSS Grid。
- 网格使用 6 个等宽列和 3 个等高行，应用项保持居中对齐。
- 移动端在现有掌机设计尺寸内缩小图标与间距，确保 18 个应用和顶部状态栏同时可见。
- 不改变标题栏手机按钮、顶部红点或其他视图的尺寸和行为。

## 实现边界

- 修改范围限定为 `src/phone.js`、手机主页相关 `src/styles.css` 和契约测试。
- 不重构应用导航，不修改任何存档字段，不改变桌面端与 Android bridge。
- 删除分页专用的运行时代码，保留调试布局输出中的 `phonePages` 查询以便诊断。

## 验证标准

1. 手机主页源码不再按 `PAGE_SIZE` 切分，也不生成页码圆点或绑定滚轮翻页。
2. 应用数组仍包含 18 个唯一入口，点击委托仍覆盖全部应用 ID。
3. CSS 明确提供 6 列 × 3 行的单屏网格且不允许横向滚动。
4. `npm run test:mobile`、完整 Node 测试、语法检查和 Web 资源构建全部通过。

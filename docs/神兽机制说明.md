# 神兽怎么遇？——当前版本说明

**「神兽」指什么**：本作把带神兽标记的 190 只统称「神兽」。按原作的官方称呼，这批宝可梦分成四类：

- **传说的宝可梦**（民间叫「神兽」，如超梦、洛奇亚、固拉多）
- **幻之宝可梦**（民间叫「幻兽」，如梦幻、玛纳霏、玛夏多）
- **究极异兽**（如虚吾伊德、爆肌蚊、纸御剑）
- **悖谬宝可梦**（民间叫「悖论种」，如雄伟牙、铁包袱、轰鸣月、故勒顿）

它们都不进普通野池，目前只有三条获取途径。

## 一、每日神兽池（挂机就能遇到）

每个地区每天随机分到几只，按「该地区神兽总数 ÷ 8、四舍五入、至少 1 只」：

| 地区 | 今日池里几只 | 该地区神兽总数 |
| --- | --- | --- |
| 关都 / 城都 / 卡洛斯 | 1 | 5 / 6 / 10 |
| 丰缘 / 伽勒尔 | 2 | 13 / 18 |
| 合众 | 3 | 22 |
| 神奥 | 4 | 34 |
| 帕底亚 | 5 | 37 |
| 阿罗拉 | 6 | 45 |

**规则**

1. 每次遇敌先单独掷一次：**平时 1/600**，**甜甜蜜 / 闪耀护符生效期间 1/120**（5 倍）。
2. 掷中就从「今天的地区池」里**等概率抽 1 只**，现身等级**固定 Lv20**。
3. **软保底**：连着 **200 场**没出，**第 201 场必出**；计数跨天保留，出了才清零。
4. 捕获后个体值保底 **3V**：随机 3 个不同维度固定 31，其余 3 项正常随机。

**实际频率**（普通挂机约 3 分钟一次遇敌）

| 玩法 | 频率 |
| --- | --- |
| 平时挂机 | 约 **8.5 小时一只**（一天 2~3 只），其中**七成以上靠保底** |
| 开着甜甜蜜 / 闪耀护符 | 约 **37 分钟一只** |
| 指定某一只 | 关都 / 城都 / 卡洛斯（池里 1 只）约 **9 小时**；阿罗拉（池里 6 只）约 **51 小时** |

**细节**：池子每天换一次（跨天后的第一次遇敌时重分）；同一只可以反复遇到；树果方块引不出神兽；护符的「下一只必定闪光」与闪光加成**对野遇神兽不生效**（按基础 1/1000）；神兽不进大量出没和钓鱼，也不作为交换市场的对价。

**个体值**：每日池与时空扭曲抓到的神兽都保底 **3V**（随机 3 项 31，其余 3 项 0~31）；彩蛋 ZTMYO 给的是闪光 **6V、Lv100** 神兽。

## 二、时空扭曲（最快的路）

事件点每 **40~90 分钟**生成一次、存在 **30 分钟**，每次最多遭遇 **5 只**，其中**约 16~17% 是神兽**（从「非本地区」的全体宝可梦池随机抽）。蹲着抓**约 0.75 只/小时**，是目前效率最高的来源。扭曲里的神兽等级 1~20 随机、闪光率 1/200，且四成带 RGB / 污染外观变体；神兽保底 **3V**。

## 三、彩蛋 NPC（撞运气）

交易市场极小概率出现的 **ZTMYO**，给的是**闪光 6V、Lv100** 神兽，不构成稳定来源。
